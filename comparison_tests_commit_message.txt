## Quantified Performance Results

### Setup Performance Analysis
- **Baseline DKG**: 16.46ms (n=16, t=7, batch_size=32)
- **AttestedSetup**: 49.73ms (same parameters)
- **Performance impact**: 3.02x slower (acceptable for coordination benefits)
- **Dev attestation overhead**: ~0ms (Ed25519 signatures are very fast)

### Memory Usage Characteristics  
- **Baseline memory**: ~2.09 KB (2,144 bytes)
- **AttestedSetup memory**: ~3.62 KB (3,712 bytes)
- **Additional overhead**: ~1.53 KB for share commitments + transcript digest
- **Overhead breakdown**: 16×96 bytes (G2 commitments) + 32 bytes (digest)

### Cryptographic Validation Results
- **CRS structure match**: ✅ 100% (32 powers in both approaches)
- **Share count match**: ✅ 100% (16 shares generated identically)
- **Share commitment correctness**: ✅ Perfect (0 errors out of 16)
- **Lagrange reconstruction**: ✅ Correct pk-from-commitments recovery
- **Ed25519 signatures**: ✅ Valid 64-byte signatures with successful verification
